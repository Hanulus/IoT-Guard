# Interview Guide (potential users)

Duration: 10 to 15 minutes. Language: Russian or Kazakh, notes are written in English.
Before starting: explain the project in one sentence and ask permission to take notes. No names are recorded.

## Part A. About the user

1. Is this for your home or for an office? How many people use the network?
2. Which smart devices do you have? (cameras, doorbell, speakers, plugs, TV, vacuum, printer, other)
3. Who set them up, and did anyone change the default passwords?

## Part B. Awareness and experience

4. Do you know what these devices send to the internet? Have you ever checked?
5. Has any device behaved strangely (slow network, unknown logins, camera moving, router lights blinking)?
6. Do you use any security tool for the network now (antivirus on PC, router app, Firewalla, nothing)?

## Part C. Needs

7. If one of your devices was hacked, how would you like to find out?
8. What should an alert look like for you: a simple "device X is suspicious" or details?
9. Where would you check alerts: phone notification, Telegram, web page?
10. What would you do after the alert (unplug, call someone, ignore)?
11. How many false alarms are acceptable for you: per day, per week, per month?
12. Would you keep a small extra box (like a Raspberry Pi) near the router, or run a program on your PC?
13. How much would you pay for this, if anything?
